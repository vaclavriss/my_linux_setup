# my_linux_setup
Useful tools that accelerates me to be more effective.

## Layout

| Path | Contents |
|---|---|
| `install.sh` | runs the modules below in order |
| `modules/` | `basic` → `zsh` → `pet` → `nvim` → `git-tmux` → `sway-waybar-wofi` → `yazi` → `theme-wallpaper` → `utils` |
| `dot_files/` | configs, installed to `~` (`.config/` → `~/.config/`, `local/bin/` → `~/.local/bin/`) |
| `docs/` | how things work and how to set them up again |
| `backups/` | original configs from before larger changes, for restoring the old look |
| `pet/` | pet binary |

## Install on a new machine

```sh
git clone git@github.com:vaclavriss/my_linux_setup.git ~/git/my_linux_setup
cd ~/git/my_linux_setup && ./install.sh          # THEME=<palette> ./install.sh to choose colours
```

A single module can also be run on its own, for example `bash modules/theme-wallpaper.sh`.

## Colour themes and animated wallpaper

Two commands drive the look:

- `theme <palette>` switches the colours of sway, waybar, tmux, foot, wofi, zsh/p10k, yazi
  and nvim at once.
- `wallpaper` runs calm ASCII scenes, colour-matched to the palette, behind a translucent
  foot: bonsai, forest animals, planets and meteors, night sky over mountains, aquarium,
  a rotating galaxy, and eight full-colour ascii.rest scenes drawn as coloured ASCII.

See [docs/theme-and-wallpaper.md](docs/theme-and-wallpaper.md).

## Known issues (not fixed yet – check during the next fresh install)

`install.sh` installs the theme / wallpaper setup, but on a clean machine these older
parts may stop it or leave things incomplete:

- **oh-my-zsh pauses the install** (`modules/zsh.sh`): its installer ends with `exec zsh`,
  so the install waits until you type `exit`. Fix: run it with `RUNZSH=no` (and
  `CHSH=no KEEP_ZSHRC=yes` if wanted).
- **apt asks for confirmation** – `apt install` without `-y` in `modules/nvim.sh` (line 8)
  and `modules/sway-waybar-wofi.sh` (lines 21 and 46).
- **yazi config is not installed** – `modules/yazi.sh` installs yazi and the flavors but
  does not copy `dot_files/.config/yazi` (`yazi.toml`, `init.lua`, `package.toml`,
  plugins). Colours still work (`theme` generates `theme.toml`).
- **ROS lines in `.zshrc`** – `source /opt/ros/jazzy/setup.zsh` and
  `source ~/ros2_ws/install/setup.zsh` print an error in every new shell until ROS and
  the workspace exist. Fix: `[[ -f <file> ]] && source <file>`.
- **Harmless "ERROR: source ... does not exist"** for `dot_files/.zshenv`
  (`modules/zsh.sh`) and `dot_files/.config/kitty` (`modules/sway-waybar-wofi.sh`);
  neither is needed any more (kitty's `wallpaper.conf` is generated by `theme`).
- **`set -euo pipefail` aborts everything after the first failure** – modules are sourced
  into one shell, so e.g. `ya pkg add` failing without network skips all later modules,
  including `theme-wallpaper`. Rerun the remaining modules one by one
  (`bash modules/<name>.sh`).
- **Machine-specific bits** – `output DP-1 scale 1.5` in the sway config and absolute
  `/home/vaclav/...` paths in `.zshrc` (fine with the same user name).
- The old duplicate tree `dot_files/config/` (without the dot) is not used by any module.
